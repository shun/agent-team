# ADR-0026: チーム計画の参加・ゲート・実行境界

> 状態: 承認済み（2026-08-16 人間「PLAN承認」 / 2026-08-22 文面承認） /
> 起案: 人間 / 整理: Aira

## 背景

人間が「〜を計画して」と依頼したとき、7役が判断材料を揃え、承認後に
`tmp/PLAN.md` を完了まで回す流れが必要になった。当時 Rin は、safety 上の
`tmp/` 禁止、Markdown をシェルとして解釈する注入、readiness の実行許可化を
P0-1 / P0-2 / P0-3 として指摘した。人間は D-01〜D-09 を採用し、D-03 / D-04 /
D-08 でその3件へ答えた。本 ADR は採用値を固定する。

当時 P0 の見出し原文:

- P0-1: `tmp/PLAN.md` の「狭い例外」は、現行 safety と実行状態の用途を
  両立できていない
- P0-2: Markdown の自由記述を Bash dispatch が解釈する境界は、
  コマンド注入を防ぐ契約がない
- P0-3: Readiness を実行許可へ昇格させる権限境界が未決である

## 決定

| ID | 判断 | 採用値 |
| --- | --- | --- |
| D-01 | 討議の参加者 | 計画フェーズは Aira + 6役を必須。欠けたら PLAN を作らない。承認済み PLAN の実行中は、担当と Aira だけで回す。 |
| D-02 | 不明点のゲート | material な不明点が1件でも残れば質問だけ返す。 |
| D-03 | PLAN の置き場 | `tmp/` は一時置き場としてさわってよい。実行台帳は `tmp/PLAN.md`。正本にはしない。 |
| D-04 | 実行許可 | 人間が当該 PLAN の開始を1回承認したあとだけ起動する。自動ループはしない。 |
| D-05 | 完了とチェック | 実行担当は証拠を残す。Aira が完了条件を確認してからチェックする。 |
| D-06 | 並行と状態 | 初回入口の起動は直列。状態更新は1件ずつ。 |
| D-07 | 再実行と停滞 | 同一根拠で進展なしが2回続いたら blocked。 |
| D-08 | 入力境界 | 検証済みタスク ID と固定 runner 種別（`none` / `aira` / `deno` / `codex` / `agy` / `cursor`）だけ。fail-closed。 |
| D-09 | 途中課題 | すぐ知らせ、今の作業をやりきる。着手可否は区切りで相談する。 |

追加の固定:

- readiness（成果物が揃ったこと）は実行許可ではない（D-04）
- ランナーは Markdown 本文をシェルコードとして解釈しない（D-08）
- PLAN 開始承認は、「実装テーマ向けフロー」の実装承認を含まない。
  リポジトリの既存ファイル更新は、種別にかかわらずその節または safety の
  該当節へ送る。本 ADR だけでは開始しない
- PLAN 開始承認は、safety 1節・2節の操作（ADR 正式追加、正本変更、削除、
  VCS）を含まない。正本ドラフトを PLAN 内で作る場合も Rin 必須と人間承認は
  省略しない。D-01 の実行体制は、この必須を外す根拠にしない
- D-03 の置き場定義は [ADR-0024](ADR-0024-tmp-scratch-workspace.md) と同じ値である。
  実行状態は `tmp/PLAN.md` だけ。`docs/work/plans/PLAN.md` は凍結写しであり、
  実行に使わない

## 当時 Rin P0 との対応

| 指摘 | 要旨 | 答えた採用値 |
| --- | --- | --- |
| P0-1 | `tmp/` 禁止と実行台帳の衝突 | D-03。用途定義の正本化は ADR-0024 |
| P0-2 | Markdown 自由記述のコマンド注入 | D-08。検証済み ID と固定 runner 種別だけ |
| P0-3 | readiness の実行許可化 | D-04。開始の1回承認。自動ループなし |

本表は対応関係である。見出し原文は上に残す。

## 理由

計画フェーズで観点を欠かさず、不明点を仮定で埋めず、実行を人間の開始承認に
結びつける。機械が読む入力を最小にして注入面を閉じる。

## 捨てた選択肢

- 計画フェーズの欠員を Aira が代行する
- 不明点が残っても PLAN を出す
- PLAN 完成を自動実行の許可にする
- Markdown 本文をシェルまたは prompt 命令として解釈する
- 初回入口から独立 Wave を並行起動する

## 影響

- `docs/agent/guide.md` に要約済み
- `docs/agent/workflow.md` 10節へ計画手順を追加する
- `.agents/skills/team-plan/SKILL.md` の運用版置換は本 ADR の範囲外
- 判断材料の凍結写しは `docs/work/plans/PLAN.md`。実行状態ではない
