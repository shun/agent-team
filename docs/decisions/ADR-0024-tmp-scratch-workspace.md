# ADR-0024: tmp/ をエージェントの一時置き場とする

> 状態: 承認済み（2026-08-16 人間判断 / 2026-08-22 文面承認） / 起案: 人間 / 整理: Aira

## 背景

`safety.md` は `tmp/` の参照・変更を禁止していた。チーム計画の実行台帳を
`tmp/PLAN.md` に置く要求と衝突した。人間は「tmp 以下はエージェントたちの
一時置き場だからさわってもいい」と明示した。

当時の Rin P0-1 は、書込みだけを許す狭い例外では、読み取りによる状態遷移が
なお禁止に触れ得ると指摘した。本決定は禁止の例外ではなく、`tmp/` の用途を
一時置き場として定義し直す。

## 決定

- `tmp/` はエージェントの一時置き場として作成・更新・読み取りしてよい
- 正本にはしない。正本として参照・引用しない
- 実行台帳は `tmp/PLAN.md` だけとする。正本にはしない
- `docs/work/plans/PLAN.md` は人間判断時点の凍結写しである。実行状態ではない。
  ランナーは読まない。写しを正本として引用しない
- 秘密情報・生ログは書かない
- 未完了の既存計画は上書きしない
- 用途不明な既存ファイルの削除や、`tmp/` 全体の削除は人間に確認する

## 理由

作業層の `docs/work/` とは別に、実行中の使い捨て台帳を置ける。
正本化しないことで、一時ファイルがチーム定義の根拠になることを防ぐ。

## 捨てた選択肢

- `tmp/` 禁止を維持し、PLAN を `docs/work/plans/` だけに置く
- `tmp/` を正本として引用する
- 書込みだけ許し、読み取りは禁止する: 実行台帳として使えない

## 影響

- `docs/agent/safety.md` 2節・4節、`docs/agent/workflow.md` 2節へ反映済み
- 計画フローの置き場は [ADR-0026](ADR-0026-team-plan-orchestration.md) の
  D-03 と同じ値である
