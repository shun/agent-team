# ADR-0023: 共通入口を docs/agent/guide.md とする

> 状態: 承認済み（2026-08-16 人間判断 / 2026-08-22 文面承認） / 起案: 人間 / 整理: Aira

## 背景

ルートの `AGENTS.md` にチームの使い方を置いていた。導入先は Claude / Codex /
Antigravity / Cursor で入口ファイルが違う。ルートファイルを配布すると、
導入先の既存コンテキストを奪う。

## 決定

- 配布する共通入口は `docs/agent/guide.md` とする
- 各リポジトリのルートコンテキストは、このファイルを読む一文を人間が追記する
- このリポジトリの `AGENTS.md` は、固有事情だけを残す薄い入口にする
- インストーラはルートのコンテキストファイルを作成・上書きしない

## 理由

元メモも、AGENTS.md は薄く、詳細は docs 側、としている。
ツールごとの入口を配らず、docs の正本を共有する。

## 捨てた選択肢

- 下流向け `AGENTS.md` を生成して上書きする: 導入先の既存入口を奪う
- 共通入口を `docs/agent/context.md` にする: 今回 guide を採用した

## 影響

- `docs/agent/guide.md` を正本として作成済み
- ルート `AGENTS.md` は薄い入口へ整理済み
- インストーラの非対象にルートコンテキストを含める（ADR-0027 と整合）
