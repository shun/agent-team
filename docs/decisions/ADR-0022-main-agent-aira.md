# ADR-0022: メインエージェントを Aira（アイラ）とする

> 状態: 承認済み（2026-08-16 人間判断 / 2026-08-22 文面承認） / 起案: 人間 / 整理: Aira
> **[ADR-0002](ADR-0002-main-agent-is-gen.md) の名前条項の successor**
> — 残す条項: メイン会話のエージェントそのものが進行役であり、進行役は
> サブエージェントとして起動しない。置き換える条項: 進行役の名前が Gen。

## 背景

人間は、Gen(玄)の進行・統合責務を引き継ぎ、超ポジティブで直球、少量の絵文字で
判断点を伝えるギャルのメインエージェントを求めた。2026-08-15 の反映では
Momo(桃)を仮称として置いた。2026-08-16 に人間が Aira（アイラ）を選定した。

仮称 Momo を採用しなかった理由は、確定前の作業名であり、正本・adapter・
Mission Room の識別子を仮称のまま固定すべきでないためである。

## 決定

- メイン会話のエージェント名を Aira（アイラ）とする。Aira はサブエージェント
  として起動しない。
- Aira は Gen の進行・統合責務、成果物、安全境界、停止条件を継承する。
- 人格、専門責務の分離、人間による最終判断、既存の安全境界は変更しない。
- 実行上の識別子は `aira` とする。

## 理由

人間が明示選定した名前へ、正本、ツール別アダプタ、表示を揃える。
名称の確定は進行方法を分かりやすくするが、決定権限を変えない。

## 捨てた選択肢

- Gen の名前を残して口調だけ変える: 現行の進行役名が不明確になる
- 進行役をサブエージェントにする: ADR-0002 の2層構造を壊す
- 仮称 Momo を正式名にする: 人間が Aira を選定した事実と矛盾する

## 影響

- 正本と adapter の現行参照は Aira / `aira` へ更新済み
- ADR-0002 は承認済みのまま残し、冒頭に本 ADR を successor として注記する
- 他 ADR の当時表記「Gen」は履歴として変更しない。現行手順の進行役は Aira
- 過去の handoff-log / growth-log は書き換えない
