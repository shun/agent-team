# ADR-0002: メイン会話 = Gen の2層構造(Gen をサブエージェントとして起動しない)

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-05(判断自体は同日の人間の構造決定)
> **名前条項の successor: [ADR-0022](ADR-0022-main-agent-aira.md)**（2026-08-16 人間判断）
> — 進行役の名前は Aira。2層構造（メイン会話が進行役、進行役は
> サブエージェントにしない）は本 ADR が存続する。当時表記 Gen は履歴。

- **背景**: Stage 0 で `.claude/agents/gen.md` を作りサブエージェントとして Gen を起動したが、サブエージェントはメイン会話の文脈(人間との対話履歴)を持てず、進行・統合役として機能しない
- **決定**: メイン会話のエージェントそのものが Gen として振る舞う。サブエージェントは Gen 以外のメンバー(Rin 以降)専用とし、`.claude/agents/` は起動用の薄いアダプタ、ペルソナ正本は docs/agent/team.md に置く。`.claude/agents/gen.md` は削除
- **理由**: 進行役は人間との対話・依頼整理・統合を担うため、メイン会話の文脈を直接持つ必要がある。定義の正本を docs に集約すれば、他ツール(Stage 6 の Codex 等)への展開もしやすい
- **捨てた選択肢**: (a) Gen もサブエージェントとして起動 — 文脈を失い、依頼の入口役を果たせない。(b) 正本を .claude/agents/ に置く — Claude Code 専用の場所に正本が閉じ、ツール非依存の原則に反する
- **影響**: AGENTS.md「メインエージェント」節 / team.md「動作形態」節に明文化済み
