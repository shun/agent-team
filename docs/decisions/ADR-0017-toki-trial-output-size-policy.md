# ADR-0017: Toki試運転の出力量は目安と必須内容を分離する

> 状態: **承認済み（2026-07-19 人間承認）** / 起案: Gen（玄）

Toki初回試運転では、固定母集団、必須セクション、テスト項目属性を保ちながら、
人間がレビューできる出力量を管理する必要があった。

- **決定**: 320行前後をレビュー可能性の目安とし、絶対上限にしない。
- **決定**: 必須契約の充足を優先し、行数調整のために固定母集団、必須属性、
  未被覆、オラクル、追跡情報を省略・過剰集約しない。
- **決定**: 超過時は実行行数、超過理由、圧縮しなかった必須要素を記録する。
- **決定**: 行数超過だけを停止条件または不合格理由にしない。
- **理由**: レビュー負荷を可視化しつつ、数値目標が重要情報を削る誘因になることを
  防ぐため。
- **捨てた選択肢**: (a) 320行を絶対上限にする、(b) 行数目安を置かない。
- **結果**: 初回成果物`test-analysis.md`は379行で、320行目安を59行超過した。
  固定母集団51要素、リスク、カバレッジ、テスト条件、具体項目11件の必須属性、
  未被覆、オラクル、追跡情報を省略しないための超過である。成果物SHA-256は
  `3c0594e6a1d3eadf6c058161d4392848f37a8c36f1c04acf3eb5622306291c59`。
  人間は行数超過を許容し、`CD-01`を別の契約差分として残したまま内容を条件付き採用した。
- **影響**: 将来のタスク契約で本方針を使う場合も、対象ごとに目安と必須内容を明示する。
