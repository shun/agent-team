# ADR-0018: 5人構成の標準ワークフロー

> 状態: **承認済み（2026-07-19 人間承認）** / 起案: Gen（玄）

Shino、Kai、Toki、Rinが加入済みとなり、Gen一人向けの最小フローとteam正本が
一致しなくなった。

- **決定**: 標準フローを、人間 → Gen → Shino → Kai → Toki → Rin → Gen統合 →
  人間判断 → 正本反映 → 必要に応じた実装とする。
- **決定**: 専門工程が非該当の場合、Genは省略理由と未取得の観点を
  `current-task.md`へ記録する。
- **決定**: エージェント間はMarkdown成果物で連携し、入力・出力allowlist、停止条件、
  再試行上限、fallback禁止をタスクごとに指定する。
- **決定**: Rin原則1周、P0/P1の明示判断、人間最終判断、正本保護、handoffを維持する。
- **理由**: 専門責務を混ぜず、反対意見を含む判断材料を人間へ統合するため。
- **捨てた選択肢**: (a) Gen一人向けフローを維持する、(b) 全依頼で5人全員を
  無条件に起動する。
- **影響**: `workflow.md`を標準フローへ更新し、Stage 4を条件付き完了とする。
