# ADR-0005: handoff-log(セッション記録)と growth-log(定義変更)の使い分け(Q3)

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-05(判断自体は Q3 での人間の確定)

- **背景**: 記録には「セッションを跨いで文脈を引き継ぐための作業記録」と「定義がなぜ・どう変わったかの履歴」の2種類があり、混ぜると後から追えなくなる
- **決定**: `.ai/board/handoff-log.md` はセッションごとの作業記録(日時 / 担当 / 参照した成果物 / 判断したこと / 残課題 / 次に見るべきもの)。`.ai/board/growth-log.md` は定義変更=成長ループ専用(日時 / 提案 / 試した結果 / 人間の判断 / 反映先)。どちらも新しいものを上に追記
- **理由**: 用途が違う(文脈回復 vs 変更履歴)。1ファイルに混ぜると、セッション再開時に読むべき量が増え、定義変更の経緯も埋もれる
- **捨てた選択肢**: (a) 1ファイルに統合 — 上記の理由で検索性・回復速度が落ちる。(b) growth-log のみ — セッション間の文脈引き継ぎが人間の口頭説明頼みになる(実際に Stage 1 で不便が確認された)
- **影響**: workflow.md 5節に明文化済み。Gen の定義(team.md 責任節)に handoff-log の読み書きを追加(成長ループ1周目)
