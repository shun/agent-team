# ADR-0006: 設計メモの docs 移行は各ステージで少しずつ+凍結コピー(Q4)

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-05(判断自体は Q4 での人間の確定)

- **背景**: 設計思想の元ネタ tmp/memo.md は jj 管理外にあり、消失リスクがある。一方で docs/ への一括整理は、未検証のルールを大量に正本化してしまう
- **決定**: (1) tmp/memo.md は docs/notes/original-memo.md に凍結コピーし(冒頭に「参考資料・凍結・正本ではない」と明記)、以降の参照はコピーに対して行う。(2) docs/ への整理は一括でやらず、各ステージで実際に対応した内容だけを正本 docs に書き足す
- **理由**: 消失リスク対策(コピーは jj 管理下)と、成長型ブートストラップ([ADR-0003](ADR-0003-growth-bootstrap.md) 参照)の「検証されたものだけ正本化する」原則の両立
- **捨てた選択肢**: (a) 一括で docs/ に整理 — 未検証ルールの大量正本化。(b) tmp/memo.md をそのまま参照し続ける — jj 管理外で消失リスクが残り、編集されると参照が揺れる
- **影響**: safety.md 2節(tmp/ 参照禁止・凍結コピー編集禁止)に明文化済み
