# ADR-0013: 閲覧目的の jj 3コマンドを許可(safety 初緩和・判断B)

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-06(判断B。Rin レビュー2周を経て反映)
> **[ADR-0004](ADR-0004-vcs-human-only.md) を部分 supersede** — ADR-0004「VCS 操作は人間のみ・一切実行しない」の例外を、閲覧3コマンドに限って開ける。ADR-0004 は本 ADR の3コマンドを除いて有効。

- **背景**: ADR-0004 で全エージェントの VCS 操作を「一切実行しない」としたが、Gen が大きな上書きの前に未コミット差分を確認する手段がなく、作業喪失に無防備だった(Rin 指摘 P1-4)。safety.md ヘッダは「緩和には人間の明示承認 + growth-log 記録を必須とする」と定めており、本件はその初適用・初の前例
- **決定**: 差分・状態・履歴の閲覧目的に限り、`jj st`(=`jj status`)/ `jj diff` / `jj log` の3コマンドを全エージェントが実行してよい。厳守条件:
  - (a) 3コマンドも jj 仕様上、作業コピーのスナップショット(op log 記録)を伴うが、副作用込みで許可する。履歴・コミット内容の書き換えは従来どおり不可
  - (b) 素の形で使う。当該リポジトリのルートで、追加オプション・追加環境変数なしに実行する(`--tool` / `--config` / `--config-file` / `-R` 等のオプション、`PAGER` 等の環境変数を足さない — jj 経由の任意コマンド実行を防ぐため)
  - (c) 許可は列挙制。上記3コマンド以外の jj、および git を含む他 VCS は、閲覧目的でも従来どおり一切実行しない
- **理由**: 未コミット差分の確認という具体的な必要に応え、かつ「読み取りなら何でも可」の性質ベースではなく列挙制+素の形限定にすることで、拡大解釈と任意コマンド実行の穴(Rin 指摘 P1-3 / P2-6)を塞いだ。ADR-0004 の趣旨(履歴改変の防止・人間のレビュー機会の担保)は閲覧に限れば損なわれない
- **捨てた選択肢**: (a) 性質ベースの許可(「読み取り専用なら可」)— `jj op log` 等への拡大解釈の余地。列挙制に倒した。(b) 禁止側を「状態を変更しうる操作」と言い換え — jj は閲覧系も作業コピーをスナップショットするため、例外自身が禁止に該当し「より厳しい方を適用」で無効化される(Rin 指摘 P1-1)。禁止は広いまま保ち例外を列挙する形にした。(c) `--ignore-working-copy` の常時義務化 — 直近の編集が差分に出ず、本来の用途(未コミット差分の確認)と両立しないため不採用
- **影響**: safety.md 2節 / workflow.md 2節 / team.md Rin 節 / .claude/agents/rin.md に反映済み。緩和の前例フォーマット(日付 + 判断ID + 列挙制 + 用途 + growth-log 記録)は今後の safety 緩和が踏襲する。将来 .claude/settings.json の許可リスト化に乗せる場合も「素の形のみ」の条件を落とさない
