# ADR-0004: バージョン管理操作は人間のみが行う(Q2)

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-05(判断自体は Q2 での人間の確定)
> **部分 supersede: [ADR-0013](ADR-0013-jj-readonly-relaxation.md)(2026-07-06)がこの決定の一部を上書き** — 閲覧目的の `jj st` / `jj diff` / `jj log` の3コマンドに限り緩和(判断B)。本 ADR の「一切実行しない」は、その3コマンドを除いて有効。

- **背景**: Gen が成果物を作るたびにコミットまで行うか、コミットは人間に残すかの権限設計が必要だった
- **決定**: jj(および git 等)のバージョン管理操作は常に人間が行う。Gen を含むすべてのエージェント(今後のメンバー・サブエージェントも)は一切実行しない
- **理由**: コミットは「何を歴史に残すか」の判断であり、人間が最終判断者という基本方針の適用点。エージェントの変更がコミット前に必ず人間の目を通る構造になり、正本変更の承認フローの実効性を担保する
- **捨てた選択肢**: (a) エージェントがコミットまで実施 — 承認前の変更が履歴に混ざり、人間のレビュー機会が失われる。(b) 読み取り系 jj コマンドのみ許可 — 当初は境界の説明が複雑になるとして「一切行わない」に倒して単純化した。**その後 [ADR-0013](ADR-0013-jj-readonly-relaxation.md)(2026-07-06)で、この (b) を限定的に採用**(閲覧3コマンドのみ・素の形限定の列挙制で複雑さを抑えて緩和)
- **影響**: safety.md 2節 / workflow.md 2節に明文化済み。コミットメッセージ案の提案は Gen がしてよい(workflow.md 7節)
