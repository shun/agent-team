# ADR-0011: Rin の P0/P1 指摘は明示判断の記録まで対象を確定させない

> 状態: 承認済み(2026-07-06 人間承認)/ 起案: Gen(玄)/ 2026-07-05(risk-review.md P1-3 の採用・判断D)

- **背景**: Rin の重大度 P0 は「対応するまで先に進むべきでない」と定義されるが、指摘が出たときに何が起きるかの手順がなく、未判断のまま進行できた。重大度がラベルであって制御でない(Rin 指摘 P1-3)
- **決定**: Rin の P0/P1 指摘は、人間が採用 / 却下 / 保留を**明示的に**判断し、結果を該当成果物の該当項目に記録するまで、当該対象の確定・Stage の完了をしない
- **理由**: AI が進行を止める権限を持つのは「人間が最終判断者」の原則に反する。義務にするのは判断の**記録**だけ。却下は正常な結果であり、リスクレビューがアリバイ文書化する(記録はあるが判断がない)ことだけを防ぐ
- **捨てた選択肢**: Rin に進行停止権限を与える(人間最終判断の原則に反する)/ 現状維持(P0 指摘の未判断滞留 — P1-3 の失敗パターン)
- **影響**: workflow.md 1節(変更6)。進行速度の低下は人間が受け入れ済み(判断D)。2026-07-05 の P0/P1 仕分け自体が初適用
