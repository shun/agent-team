## 1. 人間の明示承認なしに行ってはならない操作

(memo セクション20 より)

- merge
- deploy
- destroy(リソース・環境の破壊)
- DNS 変更
- DB 破壊操作
- 本番設定変更
- 本番データ変更
- 重要な設計方針の確定
- ADR の正式追加
- 外部サービス契約
- 課金設定変更
- 秘密情報の保存
- セキュリティ設定の緩和

## 2. このリポジトリ固有の禁止事項

(Stage 1 の人間の判断から追加。Q2 は確定、他は Gen 起案 → 本ドラフトの承認をもって確定)

- **バージョン管理操作(jj / git 等)は原則すべて人間が行う**: `jj describe` / `jj new` / `jj commit` を含むすべての jj 操作、および git 等の他 VCS の操作を、エージェントは原則実行しない(Q2 で確定)。**例外(2026-07-05 判断B。growth-log に記録)**: `jj st`(=`jj status`)/ `jj diff` / `jj log` の3コマンドは全エージェントが実行してよい(用途: 未コミット差分の確認)。**この3つ以外の jj、および git 等の他 VCS は、閲覧目的でも実行しない。**
  - ※1 3コマンドは素の形で使う。`--tool` / `--config`(や `-R` 等)のオプション、`PAGER` 等の環境変数を足さない — 足すと jj 経由で別の任意コマンドを実行できてしまうため(Rin 指摘 P1-3 / P2-6)
  - ※2 これらも jj 仕様上、作業コピーのスナップショット(op log への記録)を伴うが、それ込みで許可する。履歴・コミットの書き換えは従来どおり不可(Rin 指摘 P1-1)
- **正本 docs(AGENTS.md・CLAUDE.md・docs/agent/ 配下・docs/roadmap.md・docs/decisions/・.codex/ 配下全体・.claude/ 配下全体・.agents/ 配下全体 — agents/ に限定せず、将来の設定ファイルを含む)を人間の承認なしに変更しない**: エージェントはドラフト提示までとする(2026-07-05 Rin 指摘 P0-1、2026-07-18 Codex 基準委譲ループ P0-1、2026-07-22 Antigravity adapter追加時の人間依頼により列挙を拡大)
- **docs/notes/original-memo.md(凍結コピー)を編集しない**: 参考資料であり凍結済み
- **tmp/ はエージェントの一時置き場である**(2026-08-16 人間判断。growth-log に記録): 作成・更新・読み取りしてよい。実行台帳 `tmp/PLAN.md` を含む。**正本としては参照・引用しない**。設計メモの参照は凍結コピー(docs/notes/original-memo.md)に対して行う。秘密情報・生ログは書かない。未完了の既存計画は上書きしない。用途不明な既存ファイルの削除や、`tmp/` 全体の削除は人間に確認する
- **ファイル・ディレクトリの削除、リネーム・移動による実質削除をしない**(docs/work/ 配下の自分の作業ファイルの整理も、人間に提案してから行う)
- **リポジトリ外への書き込み・外部サービスへの送信をしない**(作業用一時ファイルを除く)

## 3. 禁止する振る舞い

(memo セクション20 より)

- 反対意見なしに合意済みとする
- 未確認事項を決定事項として扱う
- 人間の判断を省略する
- MVP の範囲を勝手に広げる
- 便利そうという理由だけでツールを増やす
- 長文出力で判断ポイントを埋もれさせる
- **後から「なぜこうしたのか」を問われうる設計判断を、ADR 候補(ドラフト)を残さずに進める**(2026-07-05 人間追加ルール。大小を問わない。運用手順 — いつ・どの粒度で・どこに置くか — は workflow.md に定める)

## 4. 許可されていること(境界の明確化)

- docs/work/ 配下の作業成果物は、**メインエージェントを含むすべてのエージェント**が人間の承認なしに作成・更新してよい(Q1 で確定。2026-07-05 Rin 指摘 P1-1 により、禁止側 Q2 と同様に全エージェントへ一般化)
- .ai/board/ 配下の記録(handoff-log.md / growth-log.md)の追記
- 正本 docs のドラフト・変更案の提示(反映は人間承認後)
- **ADR 候補(ドラフト)の作成**。ただし docs/decisions/ への正式な ADR としての昇格は人間の承認が必要(1 節「ADR の正式追加」と整合)
- `tmp/` 配下の一時ファイルと `tmp/PLAN.md` の作成・更新・読み取り(2026-08-16 人間判断。正本化はしない)
- 読み取り・調査・分析はリポジトリ全体に対して自由

## 5. 迷ったとき

このファイルに書かれていない操作で、取り返しがつかない可能性が少しでもあるものは、**実行せず人間に確認する**。「未確認事項を決定事項として扱わない」は操作にも適用する。
