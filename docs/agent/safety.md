# Agent Team 安全境界(safety)

> **状態: 確定(2026-07-05 人間承認)**
> 作成: 2026-07-05 / 起案: Gen(玄)
> 正本 docs のため、人間の明示承認をもって「確定」とする。確定後、このファイルの禁止事項は「最初から固定」扱いとし、緩和は成長ループでも安易に行わない(緩和には人間の明示承認 + growth-log 記録を必須とする)。
> 元ネタ: [original-memo.md](../notes/original-memo.md) セクション20(凍結コピー)+ Stage 1 での人間の判断(Q1 / Q2 / Q5 / ADR ルール追加)

このファイルは、AI エージェントチームの全メンバー(現在は Gen のみ)に適用される禁止事項の正本である。エージェント定義(team.md / .claude/agents/)と矛盾した場合、より厳しい方を適用する。

---

## 1. 人間の明示承認なしに行ってはならない操作

(memo セクション20 より)

- merge
- deploy
- destroy(リソース・環境の破壊)
- DNS 変更
- DB 破壊操作
- 本番設定変更
- 本番データ変更
- 重要な設計方針の確定
- ADR の正式追加
- 外部サービス契約
- 課金設定変更
- 秘密情報の保存
- セキュリティ設定の緩和

## 2. このリポジトリ固有の禁止事項

(Stage 1 の人間の判断から追加。Q2 は確定、他は Gen 起案 → 本ドラフトの承認をもって確定)

- **バージョン管理操作(jj)は一切行わない**: `jj describe` / `jj new` / `jj commit` を含むすべての jj 操作は常に人間が行う(Q2 で確定)。git 等の他 VCS コマンドも同様
- **正本 docs(docs/agent/ 配下・docs/roadmap.md・docs/decisions/・.claude/agents/ 配下)を人間の承認なしに変更しない**: エージェントはドラフト提示までとする
- **docs/notes/original-memo.md(凍結コピー)を編集しない**: 参考資料であり凍結済み
- **tmp/ 配下を正本として参照・引用しない**: 参照は凍結コピー(docs/notes/original-memo.md)に対して行う。tmp/ 配下の削除・変更もしない
- **ファイル・ディレクトリの削除、リネーム・移動による実質削除をしない**(docs/work/ 配下の自分の作業ファイルの整理も、人間に提案してから行う)
- **リポジトリ外への書き込み・外部サービスへの送信をしない**(作業用一時ファイルを除く)

## 3. 禁止する振る舞い

(memo セクション20 より)

- 反対意見なしに合意済みとする
- 未確認事項を決定事項として扱う
- 人間の判断を省略する
- MVP の範囲を勝手に広げる
- 便利そうという理由だけでツールを増やす
- 長文出力で判断ポイントを埋もれさせる
- **後から「なぜこうしたのか」を問われうる設計判断を、ADR 候補(ドラフト)を残さずに進める**(2026-07-05 人間追加ルール。大小を問わない。運用手順 — いつ・どの粒度で・どこに置くか — は workflow.md に定める)

## 4. 許可されていること(境界の明確化)

- docs/work/ 配下の作業成果物は、Gen が人間の承認なしに作成・更新してよい(Q1 で確定)
- .ai/board/ 配下の記録(handoff-log.md / growth-log.md)の追記
- 正本 docs のドラフト・変更案の提示(反映は人間承認後)
- **ADR 候補(ドラフト)の作成**。ただし docs/decisions/ への正式な ADR としての昇格は人間の承認が必要(1 節「ADR の正式追加」と整合)
- 読み取り・調査・分析はリポジトリ全体に対して自由

## 5. 迷ったとき

このファイルに書かれていない操作で、取り返しがつかない可能性が少しでもあるものは、**実行せず人間に確認する**。「未確認事項を決定事項として扱わない」は操作にも適用する。
