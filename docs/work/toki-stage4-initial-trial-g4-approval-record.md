## 2. 低感度確認

Genは対象全文を確認し、概念設計、仮説、未確認事項、3案の比較を中心とする
リポジトリ内Markdownであることを確認した。機密候補のパターン検索も実施した。

| 確認項目 | 結果 |
|---|---|
| 秘密情報・認証情報・API key | 見当たらない |
| 個人情報 | 見当たらない |
| 顧客データ・本番データ | 見当たらない |
| 外部送信の必要性 | なし |
| 成果物への引用・要約 | 本試運転の範囲で許容 |
| 自動パターン検索 | 該当0件 |

「見当たらない」は、本入力の目視と対象パターン検索に基づく確認であり、一般的な
機密検出能力やリポジトリ全体の無機密を証明しない。

## 3. G3固定との整合

G4確認時のG3固定対象は、承認記録のdigestと一致した。

| 対象 | 内容版 | SHA-256 |
|---|---|---|
| 初回試運転契約 | `TC-1` | `ba942a1c33ff58895f81dd58a459c6648a3248593916536bda34481dca510ca9` |
| 非公開評価計画 | `EP-1` | `44b14062ce79d90a85dfb33fd2b5a5f96183f318dfa980a92f040da6884ff53d` |

`EP-1`の5節にある未確認欄は固定版内の記録形式見本として残す。実際のG4確認値は、
G3 digestを変えない本書を正とする。

## 4. 失効条件

`architecture-options.md`の内容が変わった場合、G4承認は失効する。dispatch前に
SHA-256を再照合し、不一致ならTokiを起動せずG4へ戻す。

`test-analysis.md`、停止成果物、技術方式、sandbox・permission profile、Stage 4完了、
コミットを承認しない。
