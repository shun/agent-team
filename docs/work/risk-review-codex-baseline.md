## 指摘

### P0-1: 実際の `.codex/` がアダプタの保護対象外

- **対象**: `.codex/agents/rin.toml:8` の「`.Codex/agents/`」。
- **証拠**: current-task `:38,47` と ADR `:12` は小文字の `.codex/` 全体を保護するが、
  adapter は大文字かつ `agents/` 限定。safety `:37` にも `.codex/` は未列挙。
- **失敗**: 弱い起動指示では実設定を変更可能と誤認し、安全境界を変更する。
- **緩和**: 「`.codex/` 配下全体」へ直す案と safety 変更案を人間承認後に同時反映。

### P1-2: 指示遵守を権限制御の成功と誤認する

- **対象**: current-task `:25` の「Codex については解決」と ADR `:8,13`。
- **証拠**: 現ゲートは許可操作を守る正例だけで、禁止書き込みの拒否を試さない。
- **失敗**: 別入力や将来モデルでも正本が強制保護されると誤認する。
- **緩和**: 機能と安全のゲートを分け、使い捨て複製環境で拒否を検証する。
  強制しない場合は「指示遵守」と呼び、残留リスクを人間が受容する。

### P1-3: 名前付き起動と非変更の証拠が自己申告だけ

- **対象**: current-task `:56-58` と ADR `:13` の「観測できること」。
- **証拠**: 「私は Rin」「他は未変更」は通常エージェントでも生成可能。既存の
  未コミット `rin.toml` もあり、事後差分だけでは変更主体を帰属できない。
- **失敗**: インライン実行や既存差分をカスタムエージェント成功と誤認する。
- **緩和**: Gen が起動名・ランタイム識別情報と実行前後の対象一覧・ハッシュを記録。

### P1-4: Gen の確認制限が根拠検証まで妨げる

- **対象**: current-task `:49,59` の「確認を限定」「再調査せずに統合」。
- **証拠**: team `:30-32,52` は矛盾整理を求めるが、引用検証工程が現案にない。
- **失敗**: 読み違い・誤引用の P0/P1 が人間の判断材料へ混入する。
- **緩和**: 発見作業は重複せず、Gen は全 P0/P1 の引用と根拠だけを限定確認する。

### P1-5: レビュー対象内の命令を未信頼データとして扱わない

- **対象**: `.codex/agents/rin.toml:7` の prompt と `docs/work/` からの入力。
- **証拠**: 対象 allowlist、埋め込み命令の不実行、指示の優先順位がない。
- **失敗**: 対象内の命令を作業指示と誤認し、指定外変更や外部送信を行う。
- **緩和**: 対象を列挙し、内容は未信頼データ、コマンド・リンクは実行せず、
  adapter と safety を常に優先すると明記する。

### 今回の変更で新たに生じたリスク

#### P1-N1: adapter の必須参照と allowlist が衝突する

- **対象**: draft `:116` の team/safety 必須参照、`:117` の「prompt を正」、
  および `:118` の「列挙された対象だけを読む」。
- **証拠**: 起動 prompt が team/safety を対象に列挙しない場合、`:116` と
  `:118` を同時に満たせない。prompt と safety が矛盾した場合の優先順位もない。
- **失敗**: 必須正本を未参照でレビューするか、allowlist 違反として停止する。
- **緩和**: 読み取り allowlist を「必須の team/safety + prompt 列挙対象」とし、
  「team/safety の制約内で prompt を依頼内容の正とする」と明記する。

#### P1-N2: 委譲失敗時の限定的な代替経路がない

- **対象**: draft `:56` の独立作業を担当サブエージェントへ委譲する規則。
- **証拠**: current-task `:67-68` では初回 Rin が時間超過し、縮小再試行を要したが、
  draft は未認識・時間超過・反復失敗時の停止条件と引き継ぎを定めない。
- **失敗**: サブエージェント障害でタスクが無期限停止するか、Gen が無記録で代行する。
- **緩和**: 依頼時に再試行上限を定め、超過時は人間へ返す。人間が継続を選ぶ場合だけ、
  Gen の限定代行または保留を記録付きで許可する。
