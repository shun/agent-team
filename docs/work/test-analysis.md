## 1. テスト対象、非対象、テストベース、前提、未確認事項

### テスト対象

- 案Aのファイルシステム・文書領域投影が主張する境界、成立条件、非成立条件、限界。
- 案Bのallowlist入出力ゲートウェイが主張する認可境界、成立条件、非成立条件、限界。
- 案Cのinstructionと監査が主張する検知・事後検証、非防止性、成立条件、限界。

- テスト実行、証跡生成、実結果評価、最終pass/fail、残留リスク受容。
