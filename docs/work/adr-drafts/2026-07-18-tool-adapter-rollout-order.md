# ツール別エージェントアダプタの展開順序と比較ゲート

> 状態: 採用・[ADR-0014](../../decisions/ADR-0014-tool-adapter-rollout-order.md)へ昇格済み(2026-07-18 人間承認)
> 昇格時の確定差分: 比較順を Codex → Claude Code → Antigravity とし、fresh session の2回目スモークを Stage 3 開始前の必須ゲートとした。
> 起案: Gen(玄) / 2026-07-18

- **背景**: Stage 2 では Claude Code 用 `.claude/agents/rin.md` の実起動を確認できず、アダプタ経路が Stage 3 の前提として持ち越された。一方、現在の作業コピーには Codex 用 `.codex/agents/rin.toml` が追加され、Codex を主な実行環境として使い始めている。元ロードマップは他ツール向けアダプタを Stage 6 以降としていたため、実態と計画を再整合する必要がある。
- **決定案**: 最初に Codex で「Gen が名前付きサブエージェントへ委譲し、Markdown 成果物を受け取り、Gen が統合する」基準フローを確立する。
- **決定案**: Claude Code と Antigravity の順序は事前に確定しない。Codex で確立した同一スモークテストを両環境へ適用し、起動可能性・正本参照・権限制御・成果物受け渡し・人間の観測可能性を比較して2番目を決める。暫定順は Codex → Claude Code → Antigravity とする。
- **決定案**: ツール別アダプタは薄く保ち、役割・安全境界・ワークフローの正本は `docs/agent/` に置く。アダプタ固有の知識を正本化しない。
- **理由**: Codex は現在の主実行環境であり、最初の成功経路を最短で作れる。Claude Code は既存アダプタがあり移植コストが低い。Antigravity はマルチエージェントと成果物中心の思想に適合する可能性があるが、同一テストによる実測前に順位を固定する根拠は不足している。
- **捨てた選択肢**: (a) Claude Code を無条件で2番目に固定する — 既存ファイルへのサンクコストで順序を決めることになる。(b) Antigravity を無条件で2番目にする — 適合可能性は高いが移植・権限制御の実測がない。(c) 3環境を同時対応する — 基準フローがないまま差分が増え、問題の切り分けができない。(d) Stage 6 まで Codex アダプタを扱わない — 現在の実行環境とロードマップの乖離を放置する。
- **影響**: `.codex/` を正本保護範囲に追加し、team / safety / workflow / roadmap のツール固有記述を見直す正本変更案が必要になる。反映は Rin レビューと人間承認後に行う。
- **検証ゲート**: 各環境で、同じ Rin スモークテストが1回以上成功すること。成功とは、名前付きRinの実起動、正本の参照、指定成果物の作成、禁止領域への非変更、Genによる成果物統合までを観測できることとする。
