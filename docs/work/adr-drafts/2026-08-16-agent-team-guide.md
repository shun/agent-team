# ADR候補: 共通入口を docs/agent/guide.md とする

> 状態: 候補（人間依頼済み・未昇格） / 2026-08-16 / 起案: 人間 / 整理: Aira

## 背景

ルートの `AGENTS.md` にチームの使い方を置いていた。導入先は
Claude / Codex / Antigravity / Cursor で入口ファイルが違う。
ルートファイルを配布すると、導入先の既存コンテキストを奪う。

## 決定

配布する共通入口は `docs/agent/guide.md` とする。
各リポジトリのルートコンテキストは、このファイルを読む一文を
人間が追記する。このリポジトリの `AGENTS.md` は、固有事情だけを
残す薄い入口にする。

## 理由

元メモも、AGENTS.md は薄く、詳細は docs 側、としている。
ツールごとの入口を配らず、docs の正本を共有する。

## 捨てた選択肢

- 下流向け `AGENTS.md` を生成して上書きする
- 共通入口を `docs/agent/context.md` にする（今回 guide を採用）

## 影響

- `docs/agent/guide.md`（新規・正本）
- ルート `AGENTS.md`（整理）
- インストーラはルートコンテキストを書かない
