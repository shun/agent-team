# ADR候補: tmp/ をエージェントの一時置き場とする

> 状態: 候補（人間判断済み・未昇格） / 2026-08-16 / 起案: 人間 / 整理: Aira

## 背景

`safety.md` は `tmp/` の参照・変更を禁止していた。チーム計画の実行台帳を
`tmp/PLAN.md` に置く要求と衝突した。

## 決定

`tmp/` はエージェントの一時置き場として作成・更新・読み取りしてよい。
正本にはしない。秘密情報・生ログは書かない。

## 理由

人間が「tmp 以下はエージェントたちの一時置き場だからさわってもいい」と明示した。
作業層として `docs/work/` とは別に、実行中の使い捨て台帳を置ける。

## 捨てた選択肢

- `tmp/` 禁止を維持し、PLAN を `docs/work/plans/` だけに置く
- `tmp/` を正本として引用する

## 影響

- `docs/agent/safety.md` 2節・4節
- `docs/agent/workflow.md` 2節の書き込み表
- 実行台帳は `tmp/PLAN.md`
