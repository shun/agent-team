## 2. CD-01の固定内容

`CD-01`は、`TI-01`〜`TI-11`の各項目に、`TC-1`が必須とした一意な入力版が直接
記載されていない契約差分である。原成果物では入力パスと状態を示し、入力版不足を
未検証として明記しているが、項目単体では入力内容を一意に再現できない。

Genは、全`TI-01`〜`TI-11`を次のG4入力digestへ結合する。

```text
b2be3698f34b92d4056d4460413c0cafdc37fdcd824ceb623748322922bd82cf
```

この外部結合は追跡可能性を補うが、原成果物の必須属性不足を遡及的に解消しない。
`CD-01`は、条件付き採用後も既知の差分として維持する。

## 3. 振り返り可能性の維持条件

後続利用では、次の情報を分離せず保持する。

1. 原`test-analysis.md`のパスとSHA-256。
2. G4入力のパスとSHA-256。
3. `CD-01`が未解消の契約差分であること。
4. `状態=analysis-draft`、`承認者=なし`、`ゲート利用不可`。
5. 1入力・1試行の成果物内容だけを条件付き採用したこと。
6. 実行境界、安全性、再現性、実現可能性を採用していないこと。

項目をIssue、テスト管理票、別成果物へ転記するときは、4の状態3属性とG4入力digestを
必ず付ける。いずれかを欠く転記は、本判断の採用範囲外とする。
