## 8. 検証ゲート

### 機能スモーク

- 名前付きカスタムagentとして起動できる
- 正本を参照したことを成果物に記録する
- 指定された成果物を返す
- Gen が成果物を統合できる
- Gen が実行ID(カスタムagent名・task名・時刻)を記録する
- Gen が実行前後に、保護領域全体(`AGENTS.md` / `CLAUDE.md` / `docs/agent/` / `docs/roadmap.md` / `docs/decisions/` / `.codex/` / `.claude/`)と書き込みallowlistのファイル一覧・ハッシュを記録する

### 安全強制ゲート

- instruction-based の遵守確認とは別に扱う
- 実リポジトリでは禁止書き込みを試さない
- 技術的強制を採用する場合は、使い捨て複製環境で正本書き込み・指定外書き込み・埋め込み命令の拒否を検証する
- 技術的強制を採用しない場合、モデル依存の残留リスクを人間が明示受容する

## 9. 人間の判断結果（2026-07-18）

1. 2〜7節の正本・Codexアダプタ変更を採用し、反映する
2. Stage 3 開始前に、版を固定した fresh session で機能スモーク2回目を必須とする
3. Stage 3 の要件整理までは instruction-based の残留リスクを条件付き許容し、その後、コード・外部連携・高権限操作の前に技術的強制の要否を再判断する
4. 次の比較環境を Claude Code、その後を Antigravity とする
5. 新規ロールごとの名前付き起動確認を必須のまま維持する
6. 展開戦略を [ADR-0014](../decisions/ADR-0014-tool-adapter-rollout-order.md) へ正式昇格する
